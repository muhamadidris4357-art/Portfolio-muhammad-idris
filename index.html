Tentang

Saya adalah seorang Developer & Security Researcher asal Indonesia yang fokus pada pembuatan solusi web berkualitas tinggi.

Sebagai talenta muda di dunia rekayasa perangkat lunak, saya mendedikasikan waktu untuk menguasai teknologi web masa kini. Fokus saya terletak pada arsitektur kode yang rapi (arsitektur bersih), optimalisasi kinerja sistem, dan pengalaman pengguna (pengalaman pengguna) berstandar tinggi.

Keahlian

Menguasai HTML dan CSS sebagai fondasi utama dalam merancang antarmuka web yang terstruktur, cepat, dan responsif. HTML digunakan untuk menyusun kerangka elemen yang semantik, sementara CSS digunakan untuk mengolah tata letak dan estetika visual agar tampilan web menginspirasi di berbagai ukuran layar.


Selain itu, JavaScript diterapkan untuk menghadirkan logika dinamis dan interaktivitas pada aplikasi web. Kombinasi teknologi ketiga ini memungkinkan penyajian antarmuka yang tidak hanya menarik secara visual, tetapi juga memberikan pengalaman pengguna yang optimal dan fungsional.

HTML (HyperText Markup Language)

Mengatur tata letak visual, tipografi, dan responsivitas antarmuka.

CSS (Cascading Style Sheets)

Tidak ada sistem yang sempurna, tetapi selalu ada ruang untuk memperkuatnya.

JS (JavaScript)

Bertekad membuktikan bahwa usia muda bukanlah halangan untuk menciptakan karya teknologi berstandar tinggi dan berdampak nyata.

Project

Portofolio ini merupakan wujud eksplorasi dalam membangun antarmuka web yang berfokus pada estetika visual dan fungsionalitas. Proyek yang dibangun mencakup landing page Aura Coffee bernuansa dark-gold, halaman otentikasi pengguna yang modern, serta aplikasi fungsional seperti kalkulator digital.


Setiap proyek diawali dengan perancangan wireframe dan sistem desain di Figma, kemudian dieksekusi menjadi kode yang responsif menggunakan HTML, CSS, dan JavaScript, serta didokumentasikan dengan rapi di GitHub.

Modern Login Interface

Antarmuka masuk akun berbasis visual yang bersih dan rapi, mengutamakan kenyamanan serta kemudahan navigasi pengguna.

Aura Coffee Landing Page

Website artisan coffee shop bernuansa gelap dan emas yang dirancang interaktif untuk menyajikan menu, cerita merek, dan fitur reservasi meja.

Aplikasi Kalkulator Digital

Tool perhitungan berbasis web yang responsif dengan tata letak tombol yang presisi dan interaktif.
